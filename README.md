# Сайт Юлии Бердниковой

Адаптивная статическая реализация макета Figma **Website / Cream-Olive Homepage — Continuous**.

## Локальный запуск

Проект не требует сборки:

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Структура

- `index.html` — семантическая разметка всех секций;
- `styles.css` — визуальная система и адаптивные состояния;
- `script.js` — мобильное меню, появление секций, FAQ, фотогалерея и панель онлайн-записи;
- `assets` — экспортированные из Figma публичные изображения и графика.

## Конфиденциальность

Сканы дипломов и сертификатов намеренно не включены в публичный репозиторий: они содержат персональные данные. В публичной реализации сохранена текстовая хронология образования. Перед публикацией оригиналов необходимо отредактировать персональные данные и получить явное разрешение владельца документов.

## Перед публикацией сайта

Нужно согласовать и заменить временные сведения: телефон, e-mail, адрес приёма и юридические документы.

## Онлайн-запись

Запись ведётся через YCLIENTS: https://n2781405.yclients.ru/. Все кнопки с атрибутом `data-booking-open` открывают выезжающую панель с формой YCLIENTS во фрейме (на мобильных — на весь экран). Фрейм загружается при первом открытии. У каждой кнопки сохранена настоящая ссылка на YCLIENTS, а в панели всегда доступна ссылка «Открыть запись в новой вкладке» — на случай, если фрейм не отобразится.

Имя, телефон и другие данные клиента при записи вводятся на стороне YCLIENTS. Перед публикацией нужно отразить это в политике обработки персональных данных.
