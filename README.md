# Сайт Юлии Бердниковой

Адаптивная статическая реализация макета Figma **Website / Cream-Olive Homepage — Continuous**.

## Локальный запуск

Проект не требует сборки:

```bash
python3 -m http.server 4173
```

После запуска откройте `http://localhost:4173`.

## Структура

- `index.html` — семантическая разметка всех секций;
- `styles.css` — визуальная система и адаптивные состояния;
- `script.js` — мобильное меню, появление секций, FAQ и фотогалерея;
- `assets` — экспортированные из Figma публичные изображения и графика.

## Конфиденциальность

Сканы дипломов и сертификатов намеренно не включены в публичный репозиторий: они содержат персональные данные. В публичной реализации сохранена текстовая хронология образования. Перед публикацией оригиналов необходимо отредактировать персональные данные и получить явное разрешение владельца документов.

## Перед публикацией сайта

Нужно согласовать и заменить временные сведения: телефон, e-mail, адрес приёма, юридические документы и окончательный канал записи.
